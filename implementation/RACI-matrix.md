# RACI Matrix

Project: Disease Prediction Management System, Software Design, Dongshin University

| Letter | Meaning |
| --- | --- |
| **R** | Responsible: does the work |
| **A** | Accountable: owns the result (one per row) |
| **C** | Consulted: gives input before the work is done |
| **I** | Informed: told after the work is done |

`A/R` means the same person does the work and owns the result.
